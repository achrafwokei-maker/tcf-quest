# Product requirements

## What and for whom

TCF Quest is a personal French coach for **TCF Canada**, for one learner first (the learner), built so others can join later. Exam goal: NCLC 7 minimum, NCLC 9 target, in all four skills. Personal goal: C1/C2, tracked separately.

**Every day the learner should know what to study, why it matters, what is improving, and how far the target is.**

## Constraints

US$0 (free, local, open-source only) · runs on an Apple Silicon Mac, opened in a browser · private by default · original or licensed content only.

## Core loop

Diagnostic per skill → plan weighted to the weakest skill → short daily missions → weekly mini-trial under exam conditions → plan adjusts.

## Destinations

1. **Aujourd'hui:** greeting, today's mission and why, daily goal, streak, XP, weakest skill, next weekly trial, one clear next action.
2. **Mon Aventure:** five-region map, missions, checkpoints, bosses, mastery requirements, achievements.
3. **Entraînement:** the four skills, grammar, vocabulary, mistake revision, timed exercises, simulator.
4. **Ma Progression:** CEFR estimate per skill with range, trends, mistakes, revision, weekly history, readiness.
5. **Mon Professeur IA:** text and spoken conversation, corrections, role-play, history.

## Non-negotiable rules

Exam mode separate from training · unlocks by mastery, never points · never official scores, always estimates with ranges · CEFR, TCF and NCLC never mixed · score table versioned · AI never sets answer keys or levels.
