# Image requests

Every image is listed here **before** it is generated. The learner approves (or edits) each one; only then is it generated and saved into `web/public/art/`. Images are made during development with ChatGPT or Nano Banana (Google Flow) and are never generated inside the app.

Rules for every prompt: no text, letters or logos in the image (labels are drawn in code); original characters only (no existing brands or people); leave calm areas where the interface sits.

Status: `awaiting approval` → `approved` → `generated` → `in app` (or `rejected`).
